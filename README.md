# Blueprint Builder — Fabric 26.2

مود يخليك تحط رابط ملف مبنى (أو رابط المقطع نفسه) ويوريك **وش يحتاج من مواد**، ويعرض لك **معاينة شفافة طبقة طبقة**، و**يبنيه لك** بضغطة زر.

## التثبيت
1. ثبّت **Fabric Loader** لنسخة 26.2 + **Fabric API**
2. حط `blueprint-builder-x.x.x.jar` في مجلد `mods`
3. ملفات المباني تنحط في `.minecraft/schematics/` (نفس مجلد Litematica)

الصيغ المدعومة: `.schem` (WorldEdit v1/v2/v3) — `.litematic` — `.nbt` (Structure Block)

## الأوامر
| الأمر | وش يسوي |
|---|---|
| `/bp` | قائمة المساعدة (كل شي قابل للضغط) |
| `/bp list` | الملفات اللي في مجلد schematics |
| `/bp load <file>` | تحميل ملف |
| `/bp url <link>` | تحميل من رابط (MediaFire / Google Drive / Dropbox / GitHub / رابط مباشر) |
| `/bp video <link>` | يدور رابط التحميل في **وصف المقطع** ويعطيك زر "Use" |
| `/bp materials` | المتطلبات: كم تحتاج / كم عندك / كم ناقصك |
| `/bp preview` | معاينة شبحية للمبنى (تشغيل/إيقاف) |
| `/bp layer 1` · `up` · `down` · `all` | عرض طبقة طبقة |
| `/bp here` · `/bp rotate` · `/bp move x y z` | تحريك وتدوير |
| `/bp build [speed] [clear]` | ابدأ البناء (speed = بلوك لكل tick، clear = يفضّي الهوا داخل المبنى) |
| `/bp pause` · `resume` · `cancel` · `undo` | التحكم |

## كريتيف وسرفايفل
- **كريتيف:** يبني كل شي مجاناً.
- **سرفايفل:** ياخذ البلوكات من الانفنتوري، ويتخطى اللي ناقصك. جمّعها وسوّ `/bp build` مرة ثانية ويكمّل الباقي بس.

## ملاحظات
- المود يشتغل على السيرفر (وبالسنقل بلاير تلقائياً). اللاعبين ما يحتاجون المود عشان يشوفون المعاينة.
- تحويل **فيديو** لمبنى مباشرة مو ممكن بدقة، فالمود يدوّر على **ملف الـ schematic** في وصف المقطع.
- محتويات الصناديق/اللوحات (block entities) ما تنبني.

## البناء
`./gradlew build` (Java 25) — أو تلقائياً عبر GitHub Actions، والـ jar يطلع في Releases.
